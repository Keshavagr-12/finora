# FINORA

AI-Powered Personal Finance and Intelligent Debt Management System.

## Overview

Finora helps individuals manage income, expenses, loans,
EMIs and debt repayments using financial analytics and
artificial intelligence.

## Technology Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB + Mongoose
- AI Engine: Python + FastAPI
- Machine Learning: Scikit-learn
- Generative AI: LLM, LangChain, LangGraph
- Vector Search: MongoDB Atlas Vector Search

## Architecture

Modular monolith with a separate AI service.
